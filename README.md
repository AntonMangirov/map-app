# Картографическое приложение

Веб-приложение для работы с картами, поддерживающее WMS и WFS сервисы.

## Установка

```bash
npm install
```

## Настройка

Создайте файл `.env` в корне проекта и скопируйте в него содержимое из `.env.example`:

```bash
cp .env.example .env
```

## Запуск

```bash
npm run dev
```

## Использование

- Кнопка "Слои" - управление WMS/WFS слоями
- Клик по карте - получение информации об объектах
- Стандартная навигация Leaflet
- Цветные индикаторы показывают активные слои
